# Hoops_Project
RETRO HOOPS - Plataforma de Gestión de Torneos de Básquetbol  Una aplicación full-stack para registrar y gestionar competiciones de básquetbol,  desde ligas amateur 3x3 hasta torneos profesionales 5v5. Incluye:  - Registro de estadísticas en tiempo real - Tablero de control con cronómetro para seguimiento de cuartos
